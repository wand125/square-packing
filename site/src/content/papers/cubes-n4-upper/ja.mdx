## 要旨

$s_4(k)$ を、内部が互いに交わらない単位 4 次元立方体 $k$ 個（位置・向きは自由）が入る最小の 4 次元立方体の辺とする。厳密な証明書付きの配置（$k \le 29$ は 2 次体の数、$k = 30$ は有理数で書いたもの）により、
$$
\begin{gathered} s_4(17) \le 2 + \tfrac{1}{\sqrt3}, \\ s_4(k) \le 2 + \tfrac{1}{\sqrt2} \quad (18 \le k \le 25), \\ s_4(k) \le 2 + \tfrac{2\sqrt2}{3} \quad (26 \le k \le 29), \\ s_4(30) \le 2.9876881 \end{gathered}
$$
を示す。$k = 27$、$28$、$29$ では、辺 $2 + 2\sqrt2/3 \approx 2.9428090416$ は公開値 $2.942809214$、$2.942826011$、$2.942830937$ より小さく、差は $1.7\cdot10^{-7}$、$1.7\cdot10^{-5}$、$2.2\cdot10^{-5}$ である。$k = 26$ では、出典が公開値 $2.942809042$ について予想した閉じた式にあたる。$k = 17$ から $25$ では印字の桁まで公開値と一致する辺で、厳密な配置を与える。どの配置にも証明書がある。$k \le 29$ は $\mathbb Q(\sqrt3)$ または $\mathbb Q(\sqrt2)$ の厳密な数のファイル、$k = 30$ は有理数のファイルで、独立に書いた 2 つの検査器が、容器に入ることと 2 個ずつ離れていることを厳密な演算で判定する。$k = 25$ の配置は、辺 $2 + 1/\sqrt2$ の正方形に単位正方形 5 個を入れた配置 2 つの積で、正しさは手でも確かめる（§4）。$k = 18$ から $24$ の配置は $k = 25$ の配置から立方体を除いたもの、$k = 26$ から $28$ の配置は $k = 29$ の配置から立方体を除いたものである。$k = 30$ では、有理数の証明書で辺 $2.9876881$ を与える。公開値 $2.989568410$ より $0.0018804$ 小さい（§6）。下界は示さない。これらの辺が最適かどうかは未解決である。証明書は計算機で検査したもので、査読は受けていない。

## 記号

- 単位 4 次元立方体を $Q = c + R\,[-\tfrac12, \tfrac12]^4$ と書く。$c \in \mathbb R^4$ は中心、$R$ は枠で、列が立方体の軸である $4 \times 4$ の直交行列。容器は $[0, s]^4$。
- $h_r = \tfrac12 \sum_m |R_{rm}|$（$R$ の第 $r$ 行の $\ell^1$ ノルムの半分）。$Q \subseteq [0, s]^4$ であることは、$r = 1, \dots, 4$ で $h_r \le c_r \le s - h_r$ であることと同じ。
- 立方体の 2 本の軸が $(e_p \pm e_q)/\sqrt2$ で、残り 2 本が残りの座標ベクトルであるとき、*平面 $(x_p, x_q)$ で $45°$ 回した* という。$R$ が符号付きの置換行列である立方体を *軸に平行* という。
- *公開値* は出典（[出典](#出典)）に印字された値である。

## 2. 証明書と検査器

証明書（形式 `alg-v1`）は $k$ 個の中心と $k$ 個の枠を並べたもので、どの数も有理数の組 $(a, b)$ で $a + b\sqrt d$ を表す。$k = 17$ では $d = 3$、$k = 18$ から $29$ では $d = 2$。辺も同じ形で $(2, \tfrac13)$、$(2, \tfrac12)$、$(2, \tfrac23)$ と書く。$\mathbb Q(\sqrt d)$ の厳密な演算で次がすべて成り立つとき受理する。

1. どの枠も直交行列：$R_i^{\mathsf T} R_i = I$。
2. どの立方体も容器に入る：どの座標でも $h_r \le c_r \le s - h_r$。
3. どの組 $i < j$ にも分離軸 $a$ がある。$a$ の候補は、$R_i$ の $t$ 本の列と $R_j$ の $3 - t$ 本の列の一般化した外積（$t = 0, \dots, 3$、56 本）で、
$$
2\,|a\cdot(c_i - c_j)| \ \ge\ \sum_m |a\cdot R_i e_m| + \sum_m |a\cdot R_j e_m|.
$$

ここで $\mathbb R^4$ の 3 本のベクトル $v_1, v_2, v_3$ の一般化した外積とは、第 $m$ 成分が、$v_1, v_2, v_3$ を行に並べた行列から第 $m$ 列を除いた $3 \times 3$ 行列の行列式の $(-1)^m$ 倍であるベクトル（$m = 0, \dots, 3$）で、$v_1, v_2, v_3$ に直交し、3 本が一次従属のときに限って零ベクトルになる。零ベクトルになる候補は飛ばす。つまり証明書は、どの組も零でない候補で分離していなければならない。条件 3 は、2 つの立方体を直線 $\mathbb R a$ に射影した区間が高々 1 点でしか重ならないことを表すので、内部は交わらない（2 つの凸多面体の分離軸定理）。$a + b\sqrt d$ の符号は $a^2$ と $d\,b^2$ を比べて厳密に決め、判定に浮動小数は入らない。

本文で名前を挙げるファイル（証明書とその正規形の仕様 `SPEC-ALG.md`、`NESTING.md`、検査器）はすべて Release `cubes-n-dim-n4-certs-v3` にある（§7）。第 1 の検査器は `check_alg.py`。第 2 の検査器（`check2/`）は仕様書 `SPEC-ALG.md` だけから、第 1 の検査器を読まずに書いた。各証明書をいくつかの仕方で壊して拒否されることを確かめる試験と、手で作った小さな例が付いている。どちらの検査器も 13 本の証明書をすべて受理し、1 本あたり約 1 秒で終わる。

証明書は正規形（`SPEC-ALG.md`）で書いてある。数は既約分数。各枠は、立方体の対称性による 384 通りの同値な枠のうち辞書順で最大のもの。枠と辺を固定したうえで、動ける立方体の中心を辞書順の線形計画で押し込み、最適な頂点を厳密に読み戻す。立方体は中心の順に並べる。こうして 1 つの配置は 1 つのファイルと 1 つの SHA-256 をもつ。下の表はこのファイルから読んだもので、立方体の番号はファイルでの順番である。

**辺を決めているもの.** 以下の図は、各辺についてそれを決めている立方体と壁を示す。枠と辺を固定し、中心について辺を最小にする線形計画を解き、その双対で乗数が正になる接触と壁を取った。$k = 17$ と $25$ では、この鎖だけから辺の式が出るので、その枠では辺が縮まないことの証明になる。$k = 29$ と $30$ では、枠を固定したときの最適点で効いている接触を示すだけで、局所最適の証明ではない。

## 3. k = 17：辺 2 + 1/√3

$$
R_8 = \frac{1}{\sqrt3}\begin{pmatrix} 1 & 1 & 1 & 0 \\ 1 & 0 & -1 & 1 \\ 0 & -1 & 1 & 1 \\ 1 & -1 & 0 & -1 \end{pmatrix}.
$$
$R_8$ の行は互いに直交し長さ 1 なので、$R_8$ は直交行列である。どの行にも $\pm1/\sqrt3$ が 3 つあるので、すべての $r$ で $h_r = \tfrac12\cdot 3/\sqrt3 = \sqrt3/2$ となり、8 番はどの座標でも $[1 - \sqrt3/3,\ 1 + 2\sqrt3/3]$ を占め、$[0, s]$ に入る。8 番のどの軸も 0 でない座標を 3 つもつので、4 つの座標すべてで回っている。

## 4. k = 18〜25：辺 2 + 1/√2

$s = 2 + 1/\sqrt2 = 2 + \sqrt2/2 \approx 2.7071068$ とする。正方形 $[0, s]^2$ には単位正方形が 5 個入る。4 隅の正方形 $[0,1]^2$、$[s-1, s]\times[0,1]$、$[0,1]\times[s-1,s]$、$[s-1,s]^2$ と、中心 $(s/2, s/2)$ で $45°$ 回した正方形、すなわちひし形 $|x - s/2| + |y - s/2| \le 1/\sqrt2$ である。$|1 - s/2| + |1 - s/2| = s - 2 = 1/\sqrt2$ なので、ひし形は各隅の正方形と $(1, 1)$ のような角の 1 点でしか接しない。

**補題（積）.** $S_1, \dots, S_5$ と $T_1, \dots, T_5$ が $[0, s]^2$ の中の、内部が互いに交わらない単位正方形なら、25 個の積 $S_a \times T_b$ は $[0, s]^4$ の中の、内部が互いに交わらない単位 4 次元立方体である。

*証明.* それぞれ自分の平面で回した単位正方形 2 つの積は、枠がブロック対角の単位 4 次元立方体で、$[0, s]^2 \times [0, s]^2$ に入る。$S_a \times T_b$ の内部は $\operatorname{int} S_a \times \operatorname{int} T_b$ である。$(a, b) \ne (a', b')$ なら、$a \ne a'$ で第 1 因子の内部が交わらないか、$b \ne b'$ で第 2 因子の内部が交わらない。どちらでも積の内部は交わらない。$\blacksquare$

## 6. k = 30：辺 2.9876881

$k = 30$ の配置の辺は、証明書の有理数 $s = 2.9876880563\ldots$（分子 108 桁、分母 107 桁）で、公開値 $2.989568410$ より $0.0018804$ 小さい。2 次体の数ではない。証明書（Release `cubes-n-dim-n4k30-v1` の README にある有理数の形式）は、各中心を有理数で、各枠を反対称な有理数の行列 $A_i$ のケーリー変換 $R_i = (I - A_i)^{-1}(I + A_i)$ で与えるので、$R_i$ はちょうど直交行列になる。容器に入ることと、56 本の候補の軸による各組の分離は、§2 と同じく厳密な有理数の演算で検査する。符号付きの置換である枠はなく、4 つが $10^{-6}$ 以内でそれに近い。

## 7. 検査の再現

Release `cubes-n-dim-n4-certs-v3` とフォルダ [problems/cubes-n-dim/n4-certs/](https://github.com/wand125/square-packing/tree/main/problems/cubes-n-dim/n4-certs) に、13 本の証明書 `certs/n4k17.json`〜`certs/n4k29.json`、2 つの検査器、`SPEC-ALG.md`、`NESTING.md`（除いた立方体）、`SHA256SUMS` がある。Python 3 だけで、このフォルダから次を実行する。

```sh
# 第 1 の検査器：ACCEPT が 13 行
python3 -I check_alg.py certs/n4k*.json
# 第 2 の検査器：ACCEPT が 13 行
for f in certs/n4k*.json; do python3 -I check2/alg_check2.py "$f"; done
# 正規形
python3 -I check2/canon_check2.py certs/n4k*.json
# 入れ子と除く規則
python3 -I check2/canon_check2.py --nest certs/n4k1[89].json certs/n4k2[0-5].json
python3 -I check2/canon_check2.py --nest certs/n4k2[6-9].json
```

$k = 30$ は、フォルダ [problems/cubes-n-dim/n4k30/](https://github.com/wand125/square-packing/tree/main/problems/cubes-n-dim/n4k30)（Release `cubes-n-dim-n4k30-v1`）で次を実行する。

```sh
# 第 1・第 2 の検査器：ACCEPT
python3 -I check_cert.py certs/n4k30.json
python3 -I check2/cert_check2.py certs/n4k30.json
# 壊した写しはすべて拒否される
python3 -I check2/neg_tests.py certs/n4k30.json
```

$k = 17$ から $30$ のすべての配置は、ページ [4 次元の立方体に単位 4 次元立方体](cubes4-survey.html) で 4 次元で回しながら見られる。
