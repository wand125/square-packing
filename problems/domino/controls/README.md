# Negative controls

Each file must be rejected. The certificates are generated by `tools/make_cert.py`, and the
recorded checker-1 runs are the `*.record.json` files.

| file | what it is | why it must fail | checker 1 | checker 2 |
|---|---|---|---|---|
| `control_v4_plus_1e-3.json` | the 7-point certificate at L = v4 + 1/1000 | a packing of 4 squares with slack exists, so no certificate of total < 4 can be valid | failed | — |
| `control_v4_plus_1e-6.json` | the same at L = v4 + 1/10⁶ | as above | failed | failed: an explicit pose (u = 121/329) captures 1/2 |
| `control_v4_no_wedges.json` | `n4_cert.json` without the `wedges` field | checker 1 cannot certify the switching contact by subdivision alone | failed | (checker 2 does not use wedges, and verifies `n4_cert.json`) |

Commands (from the repository root):

```bash
python checker/check.py controls/control_v4_plus_1e-6.json --n 4 --max-depth 30 --jobs 4 \
    --u-breaks "K[-21/37;-11/37;15/37]"
```

The third control is not a mathematical failure. It shows that the wedge lemma is what closes
checker 1's proof at the extremal pose.
